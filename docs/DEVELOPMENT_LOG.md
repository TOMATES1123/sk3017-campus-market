## 二、开发日志（按日期）

### 2026-10-12（周一）环境与骨架 —— 🚩 M0
**今日进展**：确认选题（题目二 校园二手交易平台），建 Gitee 仓库与 `feature/core` 分支；安装 Python 3.13 虚拟环境与 Flask / Flask-SQLAlchemy / PyMySQL / Pillow；MySQL 建 `sk3017_market`（utf8mb4）；按"应用工厂 + 蓝图"搭出 `app/` 骨架（auth / market / user / stats 四个空蓝图），`run.py` 能启动并返回首页。
**遇到问题**：`flask --app run.py init-db` 报 `ModuleNotFoundError: No module named 'app.config'`——配置文件放在了项目根目录却用包内相对导入（见 DEBUG-001）。
**产出**：可启动的空项目 + 建表命令 + 目录结构。
**里程碑**：M0 ✅

### 2026-10-13（周二）数据模型与注册
**今日进展**：写出 6 张表的 ORM 模型：User / Category / Item / ItemImage / Favorite / Message；确定 `price` 用 `DECIMAL(10,2)`、收藏表加 `UNIQUE(user_id, item_id)`、留言用 `parent_id` 自关联；完成注册页与用户名/邮箱/密码校验。
**遇到问题**：注册成功后跳首页却仍显示"未登录"，原因是先写 `session['user_id']` 再 `session.clear()`，把自己刚写的登录态清掉了（见 DEBUG-002）。
**产出**：数据模型 + 注册闭环。
**里程碑**：M1 进行中。

### 2026-10-14（周三）登录、退出与 CSRF
**今日进展**：登录支持用户名或邮箱、`remember` 会话有效期；退出改成 POST 表单（GET 退出会被预加载触发）；实现 CSRF 工具：session 中存随机令牌，所有写请求在 `before_request` 统一校验，Ajax 走 `X-CSRF-Token` 头。
**遇到问题**：测试 `?next=https://example.com` 时页面直接跳去了外站（见 DEBUG-003）；另外 CSRF 校验在登录校验之前，未登录的 Ajax 收藏拿到的是 400 而不是 401（见 DEBUG-013）。
**产出**：完整认证模块 + CSRF 防护。
**里程碑**：M1 进行中（还差退出与错误页）。

### 2026-10-15（周四）错误页与基础布局
**今日进展**：完成 400/403/404/413/500 五个错误页与 Ajax JSON 分支；搭 `base.html`：吸顶导航、搜索框、用户下拉、flash 提示、页脚；写 `app.css` 设计变量（靛蓝主色 + 暖橙强调）与响应式断点。
**遇到问题**：`?page=-3` 时 `paginate` 抛 404（`error_out` 默认 True），列表页整页报错（见 DEBUG-004）。
**产出**：全站布局与错误处理。
**里程碑**：M1 ✅

### 2026-10-19（周一）商品模型与发布表单
**今日进展**：完成发布页表单（标题/分类/价格/成色/校区/描述/图片），服务端逐项校验：标题 4~80 字、描述 10~1000 字、价格用 `Decimal` 精确到分、分类必须存在；写 `_validate_item_form()` 统一返回字段与错误列表。
**遇到问题**：价格输入 `12.345` 能被存成 `12.35`（小数位没约束），补了 `quantize(Decimal("0.01"))`；表单错误后已选分类丢失，改成回填 `request.form`。
**产出**：可提交的商品表单（暂未接图片）。
**里程碑**：M2 进行中。

### 2026-10-20（周二）图片上传校验
**今日进展**：实现 `save_item_image()`：扩展名 → 大小 → Pillow `verify()` → 真实格式 → 最小尺寸五层校验；统一转 RGB 重编码为 jpg（去 EXIF）、UUID 重命名；前端加本地预览与 2MB 预校验。
**遇到问题**：3MB 图片直接触发 413 白屏（见 DEBUG-005）；把 `note.txt` 改名成 `note.jpg` 也能上传成功，因为只看了扩展名（见 DEBUG-006）。
**产出**：安全的图片上传链路。
**里程碑**：M2 进行中。

### 2026-10-21（周三）编辑、状态与删除
**今日进展**：完成编辑页（保留/删除旧图 + 追加新图，总数 1~3）、状态切换（在售/已售/下架）、删除商品（同时删磁盘图）；所有写操作校验 `seller_id`，非本人 403。
**遇到问题**：编辑时先删磁盘文件再提交事务，图片校验失败回滚后数据库还有记录、文件却没了（见 DEBUG-007）。
**产出**：商品全生命周期管理。
**里程碑**：M2 进行中。

### 2026-10-22（周四）演示数据脚本 —— 🚩 M2
**今日进展**：写 `app/seed_data.py` 与 `flask seed-db`：4 个用户、8 个分类、38 件商品、13 条收藏、10 组留言；用 Pillow 按分类配色生成 50 张渐变占位图（标题 + 价格 + 水印），避免依赖外部图片素材。
**遇到问题**：首次跑 seed 报 `TypeError: coordinate list must contain exactly 2 coordinates`——`ImageDraw.ellipse` 要 4 个坐标，我只传了圆心；改完又因为 `variant` 用了全局图片序号导致 `x1 < x0`（见 DEBUG-008）。
**产出**：一条命令可复现的演示数据。
**里程碑**：M2 ✅

### 2026-10-23（周五）首页列表与卡片
**今日进展**：首页查询（排除下架）、四种排序（最新/价格升降/最多浏览）、分类芯片与数量（一条 `LEFT JOIN + GROUP BY` 查出，避免 N+1）、商品卡片宏、空状态、分页组件。
**遇到问题**：`pagination` 同时是变量名和宏名，`{% from ... import pagination %}` 把变量覆盖了，页面 200 但列表永远空白且"共 件"（见 DEBUG-009）。
**产出**：首页列表可用。
**里程碑**：M3 进行中。

### 2026-10-26（周一）搜索与分页边界
**今日进展**：关键词搜索标题 + 描述，`escape_like` 转义 `\ % _`；分类 + 关键词 + 排序 + 分页可任意组合；`parse_page` 把非法页码统一回退到第 1 页；分页链接保留当前查询条件（`page_url`）。
**遇到问题**：搜索 `%` 返回全部 38 件商品（见 DEBUG-010）；分页宏在另一个模板里报 `page_url is undefined`，因为 Jinja 导入宏默认不带上下文（见 DEBUG-011）。
**产出**：可组合的搜索/筛选/分页。

### 2026-10-27（周二）详情页与同类推荐
**今日进展**：详情页图片画廊（主图 + 缩略图切换）、卖家卡片、成色/分类/校区/收藏数、浏览量自增（SQL `views = views + 1` 避免读改写丢更新）、同类商品推荐（同分类最新 4 件）。

## 三、复盘

1. **最有价值的 bug** 是三个"页面正常但功能没生效"的问题：分页宏覆盖（DEBUG-009）、ECharts 静默不执行（DEBUG-015）、`updated_at` 被刷新（DEBUG-012）。它们都没有报错，只靠肉眼比对数据才发现——以后验收要"看数据、看网络、看控制台"三件套。
2. **最省时间的习惯**是先用 SQL 把预期数字算出来，再和页面比对；看板 4 个图表的数字都是这么核对的。
3. **最该提前做的**是图片上传的顺序设计（DEBUG-007）：凡是"数据库 + 文件系统"两个存储，一定要先提交数据库、后删文件。
4. 下一阶段打算补：商品举报与信用分、WebSocket 即时聊天、Redis 缓存浏览计数。
