打开 **Git Bash**（桌面快捷方式），执行：

### 0.2 关联远程仓库并推送

## 二、把项目放进自己的 Git 仓库

本机若未安装 Git，请先安装（https://git-scm.com/download/win），然后：

```bash
cd sk3017-campus-market
git init
git add .
git commit -m "chore: 初始化校园二手交易平台项目骨架与文档"

git remote add origin https://gitee.com/你的用户名/sk3017-campus-market.git
git branch -M main
git push -u origin main
```

如果想让提交记录体现开发过程（老师会看提交历史），可以在本地按模块拆成多次提交，例如：

```bash
git commit -m "feat(auth): 注册登录与 CSRF 防护"
git commit -m "feat(market): 商品发布与图片上传校验"
git commit -m "feat(market): 分类搜索与分页"
git commit -m "feat(interaction): 收藏判重与留言回复"
git commit -m "feat(stats): ECharts 数据看板"
git commit -m "test: 52 项端到端冒烟测试"
git commit -m "docs: 开发日志、Debug 日志、报告"
```

> 不建议伪造提交日期——日志与 commit 时间对不上，老师一眼能看出来。
