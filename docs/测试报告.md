## 二、测试策略

1. **端到端自动化**：用 `requests.Session` 模拟真实浏览器（同一会话保持 Cookie 与 CSRF 令牌），
   覆盖注册登录、发布、搜索、收藏、留言、权限与异常上传。
2. **单元测试**：用 pytest 覆盖 `utils.py` 中的纯函数与图片上传校验，不依赖数据库，秒级反馈。
3. **数据核对**：用 SQL 独立计算预期值，与页面/看板数字比对。
4. **边界优先**：每个功能至少配一条"非法输入"用例，而不是只测正常流程。
5. **可重复**：测试前 `flask seed-db` 重置数据，测试脚本自身创建的商品在用例内删除。

## 七、遗留问题与说明

1. 未做多浏览器矩阵测试（Firefox/Safari 未验证），CSS 仅使用标准属性，风险较低。
2. 并发收藏的极限场景用唯一约束兜底，未做压测；浏览量在高并发下会成为写热点（已在设计文档"技术债"中说明）。
3. 自动化测试依赖已启动的服务与已 seed 的数据，属于集成测试而非单元测试；后续可为 `utils.py` 补 pytest 单元测试。

## 八、复现步骤

```bash
# 1. 准备数据库
mysql -uroot -p -e "CREATE DATABASE sk3017_market DEFAULT CHARACTER SET utf8mb4;"
copy .env.example .env    # 修改 DB_PASSWORD
pip install -r requirements.txt

# 2. 初始化演示数据
flask --app run.py seed-db

# 3. 启动服务
python run.py

# 4. 另开终端执行测试
python tests/smoke_test.py       # 52 项端到端断言
pytest tests/test_utils.py       # 9 项单元测试
```
